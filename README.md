# 📎 Project Name : Mala3by - ملاعبي
### Playground Booking Mobile Application - DEPI UI/UX Track

---
### 📌 Project Overview:
Mala3by is a user-friendly mobile application designed to help football enthusiasts in Egypt easily find, compare, and book nearby football playgrounds. The app aims to solve the common problem of time-wasting in searching for available playgrounds by providing real-time availability, transparent pricing, location-based search, and a seamless booking experience.

### 🎯 Project Objectives:
1. To conduct user research to understand the pain points of playground booking.
2. To create a clean, modern, and intuitive user interface (UI) for all users.
3. To design a smooth user experience (UX) journey from searching to successful booking.
4. To build a complete design system, wireframes, and high-fidelity prototype on Figma.
5. To provide essential features like location-based search, ratings, and secure booking flow.

### 📦 Project Scope :
**In Scope:**
- User Research (Surveys & Interviews)
- User Personas & User Journey Map
- Information Architecture & Sitemap
- Low-Fidelity Wireframes
- High-Fidelity UI Design & Design System
- Interactive Prototype on Figma

**Out of Scope:**
- Actual mobile development / coding
- Backend & Payment gateway integration (UI Design Only)

### 📅 Project Plan (5 Weeks)
**Week 1: Research & Discovery** - Market research & Competitor analysis, User interviews
**Week 2: Define & Ideation** - Personas, User Journey & Sitemap
**Week 3: Wireframing** - Low-fidelity wireframes & User flow
**Week 4: UI Design** - Design System & High-fidelity screens
**Week 5: Prototyping & Final Presentation** - Interactive prototype & GitHub documentation
